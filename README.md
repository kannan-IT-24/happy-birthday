# 🎂 Magical Birthday Surprise ❤️🦋

A magical, fully interactive birthday surprise website built with React + Vite.

## ✨ Features

- 🔐 Personalised login with custom names and password
- 🕯️ Blow the birthday candle
- 📅 Journey date counter (days together)
- 🌌 Infinity Galaxy with love counter
- 🎂 Birthday wishes with portrait photos
- 📸 Photo gallery with 15 personal memories
- 🎬 Video gallery with 4 personal videos
- 🗓️ Memorable days timeline
- 🎈 Balloon burst with surprise messages
- 🎁 Mystery gift reveals
- 💌 Personal heartfelt letter with envelope animation
- 💝 Share a memory together
- 🎉 Final birthday celebration screen
- 🎵 Background birthday music
- 🦋 Floating butterflies and hearts
- ✨ Glassmorphism, galaxy gradients, smooth animations

## 🚀 Tech Stack

- React 18
- Vite 5
- Framer Motion
- Lucide React
- Canvas Confetti

## 🛠️ Development

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deployment

Deployed on Vercel. See `vercel.json` for SPA routing config.
